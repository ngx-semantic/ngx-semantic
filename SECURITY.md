# Security Policy

## Supported versions

Security fixes are applied on the latest published `ngx-semantic` release on npm. Older major versions are not patched unless a maintainer explicitly says otherwise.

## Reporting a vulnerability

Please do **not** open a public issue for security reports that could put users at risk.

- Prefer GitHub's [private vulnerability reporting](https://github.com/ngx-semantic/ngx-semantic/security/advisories/new) if it is enabled for this repository.
- Otherwise email the maintainers through the contact details on [npm](https://www.npmjs.com/package/ngx-semantic) or open a GitHub issue **without** exploit details and ask for a private channel.

We will acknowledge the report, assess impact on the published package (the library on npm, not the workspace `package.json`), and coordinate a fix and advisory when needed.
